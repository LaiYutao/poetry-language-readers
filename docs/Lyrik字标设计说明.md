# Lyrik 字标设计记录

定稿日期：2026-10-14。设计与审定：Letter Lai。适用于策兰、里尔克、特拉克尔三册网页语音读本。

## 字样与字体

字样为 **Lyrik**，德语中指诗歌、抒情诗这一文学类别；采用首字母大写。基础字形来自读本德文诗歌正文所用的 **Times New Roman Regular**，倾斜由矢量变换完成，不替换成字体自带的 Italic 字形。

字标以 SVG 轮廓内嵌在网页中，不依赖访问者安装字体，也不需要联网加载字体。配套 SVG 保存定稿轮廓和逐字变换；复用时以该文件为准，避免重新输入文字导致字距变化。

## 最终字母参数

所有比例均相对于原始字形，不是相对于上一次试调结果。

| 字母 | 水平比例 | 垂直比例 | 向右倾斜 | 位置说明 |
|---|---|---|---|---|
| L | 1.00 | 1.20 | 8° | 保持原基线，单独拉高 |
| y | 0.93 | 0.93 | 0°，直立 | 在收紧字距后的基础上，额外向右移0.6个SVG单位 |
| r | 0.93 | 0.93 | 7° | 使用 yrik 共用缩放基点 |
| i | 0.93 | 0.93 | 7° | 使用 yrik 共用缩放基点 |
| k | 0.93 | 0.93 | 7° | 使用 yrik 共用缩放基点 |

yrik 最初整体向 L 靠近1.4个SVG单位，再应用各字的最终变换。四个小写字母的缩放基点统一为 `(15.488235, 24.899305)`，并非分别以各字中心缩放。L 的变换基点为 `(0, 24.899305)`。基线均保持在 `y = 24.899305`。

在当前网页尺寸下，1个SVG单位约为0.9324 CSS像素，因此 y 的额外右移约为0.56像素。SVG 坐标的 y 轴向下，向右倾斜以负数 `skewX` 实现。

## 三册配色

| 读本 | 色彩 | 色值 |
|---|---|---|
| 策兰《呼吸结晶》 | 青绿 | `#2A7775` |
| 里尔克诗选 | 棕橙 | `#8B6041` |
| 特拉克尔诗选 | 深蓝 | `#355570` |

内嵌 SVG 使用 `currentColor`，继承所在网页的主色。独立 SVG 为单色母版；内联使用时可通过 CSS 的 `color` 指定以上任一配色。

## 网页尺寸与交互

- SVG 的 `viewBox` 为 `0 0 62.20703 34`，显示尺寸为58 × 32 CSS像素；不再对整个字标施加纵向拉伸。
- 放在网页顶部导航栏左侧。桌面点击区域宽64像素、最小高34像素；窄屏宽58像素。
- 点击返回 `https://laiyutao.github.io/poetry-language-readers/`。下载为独立 HTML 后，字标仍完整显示；返回在线主页需要联网。
- 链接无下划线，悬停透明度为0.75；键盘聚焦时显示轮廓，辅助标签为“Lyrik · 返回主页”。
- 已移除原导出 SVG 中过紧的裁切框，避免拉高后的 L 顶部被截断。各字缩放保持基线对齐。

## 复用资源

[定稿 SVG 母版](../assets/branding/lyrik.svg)

下列变换直接对应母版中的 L、y、r、i、k；复用时同时保留 SVG 内的原始字形坐标。

```text
L: translate(0 24.899305) skewX(-8) scale(1 1.2) translate(0 -24.899305)
y: translate(0.6 0) translate(15.488235 24.899305) scale(0.93) translate(-15.488235 -24.899305)
r: translate(15.488235 24.899305) skewX(-7) scale(0.93) translate(-15.488235 -24.899305)
i: translate(15.488235 24.899305) skewX(-7) scale(0.93) translate(-15.488235 -24.899305)
k: translate(15.488235 24.899305) skewX(-7) scale(0.93) translate(-15.488235 -24.899305)
```
