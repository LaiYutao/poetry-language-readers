# 编纂指南入口

更新：2026-10-13。原合并指南现拆成两份可以独立使用的文档。

- [逐词读本编纂指南](逐词读本编纂指南.md)：重点记录阅读层次、颜色编码、词下注释与白话译文的分工、短引线、诗行节奏、排版参数，以及底本校勘与定稿流程。
- [语法手册编纂指南](语法手册编纂指南.md)：规则与普通例句的组织、诗例应用、专题和索引设计，以及同语言多读本共用手册的方法。

**新读本和新手册是两个独立项目。** 新增同语言的诗人或作品，默认复用已有手册；少量特殊问题在新读本说明。只有明确需要新语言手册或系统修订时，才启动手册编纂。

起稿时分别使用[逐词读本模板](../templates/逐词读本项目模板.md)或[语法手册模板](../templates/语法手册项目模板.md)。原合并版 v1.0 可在初始快照 `snapshot-2026-10-13` 中查阅；当前方法以这两份独立指南为准。
