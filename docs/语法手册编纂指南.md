# 语法手册编纂指南

编纂方法整理：Letter Lai 与 Codex  
独立指南版本：v1.0 · 2026-10-13  
经验来源：《策兰〈呼吸结晶〉德语语法阅读手册》v2.1 的编写与校订。

本指南用于新编或系统修订一份面向诗歌阅读的语言语法手册。**语法手册按语言和读者需要组织，可以服务多个作者、多个读本。** 新增同语言读本时，通常复用已有手册；更换诗人本身不是重编手册的理由。

## 1. 先判断是否需要启动手册项目

| 情况 | 处理 |
|---|---|
| 已有同语言手册适合目标读者，覆盖主要问题 | 直接引用其名称、版本和章节；新读本单独完成 |
| 新作品只带来少量特殊构式或词法问题 | 放入该读本的局部说明，必要时积累为后续增补 |
| 现有手册有明确错误或需要扩展一些专题 | 修订已有手册，保留版本关系，不复制成作者专属的新手册 |
| 进入新的语言，或现有手册与目标读者的需求明显不符 | 明确范围后新编手册 |

例如，布莱希特、特拉克尔和里尔克的新读本可以继续使用现有德语手册。夏尔、博纳富瓦的法语阅读项目可共用一份适用的法语手册；洛尔迦项目则根据西语资料另行判断。上述是组织方式，不表示这些新手册已经编成。

## 2. 界定读者、范围和材料

开工时写明：目标语言、读者已有基础、辅助语言、涵盖的阅读问题、采用的术语体系、主要语法资料、示例作品、编写署名和版本。

作者作品提供问题与例证，不能单独充当全部语法知识的来源。手册应使读者能够迁移到其他文本，同时如实说明尚未覆盖的范围。当前德语手册仍保留原名称和版本，不因计划复用便宣称它已经覆盖所有德语诗歌。

资料分清用途：语法书和可靠语言资料用于规则；词典用于词义、搭配及词形；可靠版本用于诗例；译本用于对读。每条来源记录实际查阅的条目或页码，不把未读资料列成已核依据。

## 3. 用阅读问题组织目录

先列读者会遇到的障碍，再按目标语言形成章节体系：

- 词类、词形与词典形式怎样辨认。
- 短语内部的限定、修饰、一致和支配怎样区分。
- 谓语如何组织参与者、补语和语序。
- 代词怎样回指，句子怎样并列、嵌套或省略。
- 时间、体、语态、情态、否定及比较怎样表达。
- 构词、诗体缩略、片段及同形歧义怎样分析。

不是每种语言都需采用这套章节名称。德语格、形容词变化和句框等章节可以较突出；英语、法语和西语的具体体系，应按各语言可靠资料重新设计。不能用德语框架替代新语言的研究。

## 4. 每章采用完整的教学链条

推荐顺序：**概念与用途 → 最小例句 → 规则或结构表 → 诗句应用 → 易混点与限度 → 查阅位置**。

1. 概念先说明能帮助读者判断什么，必要时列目标语言术语、中文与英语近似对应。
2. 用简短、自然的普通例句展示规则。自拟例句标明为教学例句，不冒充作者原文。
3. 表格给出适用条件、形式与对比，不能只列口诀；常见倾向与必然规则分开。
4. 回到诗句，以词形证据推到句法关系，再说明对理解有什么影响。
5. 对省略、同形或不同分析传统，交代能确定什么、还不能确定什么。
6. 给出资料出处、相关章节，以及可用的读本诗例定位。

诗句太复杂时先拆出局部问题，不让一首晦涩诗承担解释全部规则的任务。普通例句和诗例应互相帮助，但复杂诗例不是普遍规则的唯一证据。

## 5. 概念与术语不要混用

同一术语全书保持含义一致；中文相近名称背后若是不同概念，要专门对照。德语项目已遇到的典型问题包括：

- 名词自身的强弱变化，与冠词环境下的形容词变化分开说明。
- 物主词干表示的所属者，与整个名词短语的性、数、格分开说明。
- 一个词“有某个格”，与该形式“能明显显示格差异”分开说明。
- 限定／非限定、时态、语态、语气及分词的不同层次分开说明。
- 句法支配、词形一致与中文译为“……的”的表达分开说明。

这些是本次编纂经验，不要求别的语言照搬。采用另一语言或另一分析传统时，重新核对术语对应与适用范围。

## 6. 诗例、版本和论证记录

每个诗例至少记录作者、作品标识、行号或底本页码、采用文本及来源。已有逐词读本时，引用其已校文本并标明版本；没有读本时，也能根据可靠底本独立核对诗例，不必先编整本读本。

规则、例句和诗句解释应分别有依据。作者异文、排字差异和词义选择不能混写成语法事实；确实存在多种分析时，说明所采用的方案与限度。

修改诗例后检查正文、表格、练习答案和索引中的对应位置，防止一处修正、其他位置仍保留旧分析。

## 7. 多本读本如何共用一份手册

新读本记录“手册名称＋版本＋章节号或锚点”；页码只作为该版本的辅助定位。手册原有章节尽量使用稳定标识，未来增补时避免让旧读本的查阅入口失效。

共用规则与各作者诗例分层组织：正文讲规则，已有诗例留作例证；新增作者索引或诗例补充只在确有需要时加入。无需为了每一本新读本重写规则或更换封面作者名。

新读本可以单向引用手册。只有真正修订手册时才加入反向索引；不要求旧手册立刻列出所有后来的作品。发现错误时记录勘误并视范围发布修订版，不悄悄覆盖旧版本。

## 8. 手册自己的版式

手册以查阅和理解规则为中心，采用清晰的标题层级、短段落、结构表及紧邻的例句解释。无需把读本的每词引线搬入长篇语法正文。

表格尽量一行只承担一个比较维度，规则与例外在视觉上可分但都应易读；跨页重复表头，避免挤压列宽使例句难以辨认。标题不能孤悬，索引不能因表格被整块推后而留下一页几乎空白。

可以继承读本的低饱和配色和字体气质，但语法意义须有文字说明，不只凭颜色识别。普通例句、作者诗例、编者提示及来源应有清晰标识。Markdown 便于修改与检索，精确分页和字体以已核验 PDF 为准。

## 9. 附录与索引

按实际需求设置：

- 中文概念索引和目标语言术语／词条索引。
- 必要的英语术语反查，说明对应并非处处完全重合。
- 功能词表：同形不同功能分项，附构式、限制和短例。
- 与正文一致的速查表和练习答案。
- 已引用作品的诗例索引、来源和版本说明。

外来速查图若有简化或错误，应附勘误并与校订表区别呈现。不能因图制作整齐就直接视为可靠规则。

## 10. 校对与定稿

| 层次 | 核查重点 |
|---|---|
| 规则 | 条件是否齐全，是否把倾向写成绝对，来源是否实际支持结论 |
| 例句 | 自然度、拼写、形态、语序及中文是否一致；普通例句是否标明来源或自拟 |
| 诗例 | 底本、采用版本、人称、数、语气、回指和解释边界 |
| 全书一致性 | 术语、缩写、表格、练习答案、索引及前后交叉引用 |
| 版面与导航 | 缺字、表格溢出、跨页表头、孤行、目录、书签和附录跳转 |
| 修订回查 | 新说明是否仍与实际例句相符，修改是否同步到所有出现位置 |

本次定稿曾把诗中 *ich schritt* 的人称标注修正为第一人称单数过去时；这样的错误提示我们，应把表格里的形式重新放回实际主语和句子检查，而非只看孤立变位。

文本抽取和自动检查用于发现缺漏与边界问题，最后仍须阅读内容并查看渲染页。大范围版式修改检查全书；局部修改检查对应页面和前后页。记录实际完成的核验范围，不作“绝无错误”的保证。

## 11. 文件、版本与交接

手册独立编号、独立发布，不随每一本新读本自动升级。提交已同步核对的 Markdown、PDF、必要图片、来源及修订记录。当前仓库尚不含两册本地排版程序，未来恢复构建时先明确唯一内容来源和字体依赖。

现有策兰手册的路径与文件名保持有效。若未来确需建立语言层面的通用目录，可采用 `publications/<语言代码>/grammar/`，但这是可选的后续组织方案，不要仅为目录整齐破坏已经被引用的版本链接。

使用仓库内相对链接，不上传本机凭据与无关临时文件。原诗、译文和外来图表各自记录来源，不统一授予未经确认的开放许可。交接保留未决问题、可用构建方式、术语决定和已完成的校对范围。

## 12. 新手册起始任务

> 为［语言／目标读者］新编或系统修订语法阅读手册。先判断现有资料是否足以复用；明确本次需要新增的范围。以可靠语法资料和词典核查规则，用简短教学例句解释，再引［选定作者／作品］的可靠诗例应用。按目标语言设计章节与术语，区别词形、句法和解释。手册应能独立查阅并服务多本读本，不以新编某本逐词读本为前提。完成专题、功能词表、索引、来源和必要练习后，核对内容及 PDF 版面，提交 Markdown、PDF、必要图片和修订记录。
