# 三格式同步与网页发布说明

确定日期：2026-10-14。适用于策兰《呼吸结晶》、里尔克诗选、特拉克尔诗选。

## 维护的版本

- Markdown：完整文字稿，便于搜索、核查和引用。
- 普通 PDF：离线阅读、打印和批注，不附音频。
- 在线网页：沿用 PDF 排版，增加真人朗读、来源链接和播放进度条。

不再生成或发布单文件离线 HTML，也不再把语音 PDF 作为维护版本。以前的本地文件保留为历史存档；Git 历史不作重写。

## 内容从同一处生成

三册读本的每首诗以审核后的结构化内容为主稿，包含原文、逐词注释、白话译文、句法关系和重点句法。仓库各册的 `content.json` 保存主稿快照。Markdown 和普通 PDF 同时从主稿生成；网页书页从这次生成的普通 PDF 转换，另加播放按钮和收听索引。网页多出的一页收听说明不属于正文差异。

语法手册以 Markdown 为主稿，再生成 PDF；它不承担逐首读本的编纂规则。

修改译文或词注时，先修改主稿，再统一生成三种格式。网页中的 SVG 书页不单独修改文字。发布是整组操作，不能只替换某一种格式。

## 在线资源的组织

每册保留原来的网页地址，以兼容旧链接和页码书签。入口 HTML 保存导航、完整封面、其余书页占位及资源索引；`web/text-pages/` 保存按 PDF 坐标排放的可选择文字，以及原来的引线、底色、箭头等图形。中文正文与词注使用宋体-简 300 细体，标题粗体沿用 700；书页“播放、停止、来源”使用 400，暂停状态也保持 400。德语仍用 Times New Roman，英译附录沿用底本的 Minion 字形。网页字体渲染和 PDF 轮廓的抗锯齿可能略有不同，内容、位置和分页保持对应。

`assets/fonts/` 保存三册共享的 WOFF2 字体子集及字体样式表，字体文件名包含内容校验值。只装入页面实际用到的字体；字体在三册之间可复用浏览器缓存。中文字体目前按三册字符并集制作，首次加载不保证比旧矢量方案更快；后续书页只需文字坐标与图形，传输量明显减少。`web/audio/` 保存独立 MP3，`web/reader.css` 保存本册配色和样式。三册共用播放器脚本。

书页在接近可见区域时加载，手机端只提前加载临近 150px 范围内的书页，常规书页加载最多同时进行两项。页码书签的目标页直接加载，先定位再安排附近页面，避免从封面一路预加载；录音点击播放后才请求。文件地址带内容校验版本，改变的资源会刷新，未改变的资源可继续缓存。

德语原诗在文字选择顺序中与下方词注分开组织；英译双栏先左后右。网页音频按钮覆盖区域原本被白色遮罩隐藏的页眉文字不再重复导出，避免“逐词译注”与“来源”叠字。文字导出逐页核对字符完整性，仅排除这些已被遮罩覆盖的页眉字符。旧 `web/pages/`、`web/glyphs-common.svg` 和 `web/glyphs.svg` 暂留以兼容旧入口缓存，新入口使用 `web/text-pages/`，不再请求旧字形资源。

字形与字体子集固定非内容性的生成元数据，避免仅因重新运行程序就产生差异。改 logo 不会重新编码音频；改一页文字通常只改变相关书页及其索引，若增加字体子集中没有的新字，则相应共享字体也会更新。

## 发布前校验

1. 核对三册全部诗篇的白话译文与主稿、Markdown、PDF 一致。
2. 核对网页生成用的每个正文 PDF 页均保留普通 PDF 页的文本，且普通 PDF 没有音频动作。
3. 保存 `alignment.json`，记录主稿、Markdown、PDF、网页资源和播放器的 SHA-256，以及已执行的校验。
4. 检查目录跳转、按需加载、播放／暂停、停止和进度条；检查桌面与窄屏排版。
5. 把同一批成稿与资源一并提交，等待 GitHub Pages 部署后核对线上文件。

仓库的 `tools/check_publications.py` 可校验已发布文件是否与记录相符；主工作区的 `work/build_publications.py` 负责统一生成并校验。排版需要当前工作区的 ReportLab、pypdf、pdfplumber、fontTools、Brotli、Poppler 和既有字体及底本资源，仓库不宣称包含全部 PDF 重建依赖。
