# Poetry Language Readers · 诗歌与语言阅读

Letter Lai 的多语言诗歌逐词读本与语法阅读手册资料库。

逐词读本按诗展开，语法手册按问题查阅；二者共同帮助中文读者从词形、句法走进原文。当前已完成策兰《呼吸结晶》一组，后续计划扩展至其他作者与语言。

    assets/

## 当前保存与后续更新

这是 2026-10-13 定稿成果的初次入库，初始快照标签为 `snapshot-2026-10-13`。读本 v2.0 与手册 v2.1 独立编号。

本次未收录原始排版程序、字体、底本照片或完整参考文献 PDF，因此仓库目前不提供自动重建两册 PDF 的命令。以后修改内容，须同步生成并核验对应 PDF，再更新版本记录和 `manifest.json`；不能只修改一种格式后称为新定稿。需要恢复自动生成时，先按编纂指南明确内容来源与字体依赖。

仓库为私有。原诗、已有译文和外来图片分别保留其来源与署名；本仓库未向这些内容统一授予开放许可。
