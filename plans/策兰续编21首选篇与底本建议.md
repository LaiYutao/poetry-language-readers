# 策兰续编：21 首选篇与底本建议

短诗优先准备稿 v0.3 · 2026-10-13。Letter Lai 阅读与编纂项目。

**必选：《Corona》《Zähle die Mandeln》（数数杏仁）及《Todesfuge》（死亡赋格）。** 其余以篇幅紧凑、句法有代表性的诗为主，保留《Psalm》《Sprachgitter》《Tübingen, Jänner》等名篇。《Todesfuge》按最新要求作为名篇例外保留。

这份续编计划选取《罂粟与记忆》《从门槛到门槛》《语言栅栏》《无人之玫瑰》中的 21 首，全部避开已完成的《呼吸结晶》21 首。按原诗集分组，保留作品之间的历史次序；不把自主选篇包装成某出版社已有的“精选20首”。

当前已核题名、原集归属及若干在线正文来源；本轮主动查找了出版社、国家图书馆与诗歌机构网站，但尚未找到允许完整重编这20首及全文译注的开放版本。这份文件是选篇与研究准备稿，尚不是完成的逐词读本。线上正文可用于核查和讨论，不把“能访问”记为“已获全文再用许可”。

## 3. 选篇思路与边界

这册从已做过的《呼吸结晶》向较早的四部诗集扩展，以一册横向选读增加语汇、构词和句法材料。它不是某一组诗的全译，也不能代表策兰的全部创作。

每组保留名篇，也容纳短小、词义密集的诗。按“短诗优先、不是每篇都极短”编选，不因篇名重要就纳入长组诗《Engführung》。《Todesfuge》按用户最新要求保留为较长名篇例外。版面不以压小原文字号或行距来强行凑页。

本轮仅为已经看到明确行分隔的文本登记长度：Lyrikline 的《Zähle die Mandeln》为16行、4节，《Psalm》为20行、4节；Deutsche Lyrik 展示的《Die Krüge》为8行。这些是所列网页版本的人工计数，排除标题与节间空行，不代替最终纸本校勘。其他篇目暂不填行数，避免把屏幕自动折行误算成诗行。

正式编纂先试做《Kristall》《Sprich auch du》和《Psalm》三篇，检查短诗、命令表达及反复结构在词注和白话中的分工；这些是试编方向，具体语法结论仍须从全文分析得出。若手头选本缺少某篇，可据其实际目录替换，保持约20首规模。

## 4. 样式与编辑约定

直接沿用《呼吸结晶》成功的页面层次：原文与词下注释、白话译文、句法关系、重点说明和校对记录。续编可先采用低饱和石青主色，与原册同属冷色体系；色值在实际样页中再定。

- 原文正常词距，短引线不加箭头；原文行距稳定，诗节空白明显。
- 词注贴近词义；格、括号英文、构词分隔符及可分动词方括号为辅助色。
- 白话保留句子、从句和插入语顺序，句内允许疏通。
- 继承标注方法，不机械继承旧册的具体译词；新诗的每一处校改有自己的依据。
- 同样复用《德语语法阅读手册》v2.1，不另编策兰专属的新语法手册。
- 已有中文或英译只用于有明确来源的对读，不从网络拼成未经记录的全文附录。

## 6. 逐篇阅读重点（工作提纲）

以下是编纂时应核查的问题，不是逐句释义，也不替代诗歌正文。除上节已核查的三首外，具体标注仍需在统一底本上逐一验证。

| 篇目 | 词注与句法重点 |
|---|---|
| Espenbaum | 呼语、颜色词与物主形式；中文不要把相邻句过度补成因果关系 |
| Corona | 人称转换；间接宾语与物主词分别标格；保留并列结构和时间从句的推进 |
| Kristall | 否定表达、介词支配及反复；不要为了通顺抹平结构上的对应 |
| Die Krüge | 名词化分词及属格；主语持续性；可分动词与结果意义的分工 |
| Zähle die Mandeln | 命令式与可分动词；第二节多层关系从句；人称与指代不能在白话中合并 |
| Mit wechselndem Schlüssel | 介词短语与分词形容词；逐词保留动作本义，解释放在句法栏 |
| Schibboleth | 命令与呼语；外语词保留来源，不把历史背景硬写入逐词义 |
| Sprich auch du | 命令式、否定和并列；先核句子主干，再讨论隐喻 |
| Heimkehr | 方位、名词化形式和省略；与格／宾格按实际结构标注 |
| Tenebrae | 主语与被呼唤者的位置变化；反复的语法功能与祈祷语体分开说明 |
| Blume | 时态、代词、指示关系；同一意象在词注中保持基本译词一致 |
| Sprachgitter | 复合词、插入语及省略；识别完整句与名词片段 |
| Schneebett | 修饰语附着、感官意象的词性；不以中文顺口为由提前决定歧义 |
| Ein Auge, offen | 标题中的省略与形容词位置；正文断句与诗行分开处理 |
| Es war Erde in ihnen | 并列动词、否定和人称转换；保留叙述段落的推进次序 |
| Zürich, zum Storchen | 插入与转述层次；时间词不能无依据补成因果连接词 |
| Die Schleuse | 引语词与外语词的边界；注释交代词源，白话避免把解释塞进诗句 |
| Psalm | 否定代词与名词化称谓；第一虚拟式；复合词词素；与格支配 |
| Tübingen, Jänner | 引语、假设结构与重复；历史引文另注，不取代句法解释 |
| Mandorla | 问答结构、否定代词和介词；避免把同形词的不同功能压成同一标签 |

优先落地顺序为《Corona》《Zähle die Mandeln》《Kristall》《Psalm》《Sprich auch du》；正式读本仍按原集顺序编排。素材来源满足全文处理条件后，依次进行统一转录、逐词注释、白话译文、关系说明、影像与版式复核。用户指定的三首不因选集缺篇而替换。
